功能

一个工作区，集中查看常用子网参数。

从一个 IPv4 地址直接得到配置、排障和文档所需的信息，无需在多个工具之间重复输入。

01

子网计算

查看规范网络、可用范围、广播地址、掩码、通配符掩码和主机容量。

02

VLSM 规划

输入网络名称与主机数量，按照从大到小的顺序生成地址分配。

03

掩码转换

转换子网掩码与 Cisco 风格通配符掩码，并显示对应的连续前缀。

04

CIDR 参考

查询 /0 至 /32 的地址总数、可用主机、子网掩码和通配符掩码。

隐私

网络信息保留在你的设备上。

IPv4、掩码、通配符与 VLSM 均在本地计算。App 不需要账号、后端或分析 SDK。

本地处理地址和规划直接在 iPhone 或 iPad 上计算。
无需账号没有登录流程，也不维护云端网络清单。
由你控制复制只有点击复制操作时，结果才会写入剪贴板。

使用流程

先计算，规模扩大时再规划。

无论现场快速核对、结构化 VLSM 规划还是前缀查询，都可在同一 App 中完成。

  1. 粘贴 IPv4 地址

    使用 CIDR 表示法，或通过步进按钮与快捷标签精确调整前缀。

  2. 查看并复制结果

    集中查看网络、可用范围、掩码、广播地址和地址属性。

  3. 建立 VLSM 规划

    添加带名称的主机需求，在父网络中生成分配结果。

  4. 查询内置参考

    无需离开 App 即可搜索前缀、掩码或主机数量。
