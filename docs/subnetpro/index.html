FEATURES

The subnet answers you need, in one workspace.

Move from an address to the values used in configuration, troubleshooting and documentation without rebuilding the same calculation across several tools.

01

Subnet calculator

Enter an IPv4 address and prefix to see the canonical network, usable range, broadcast, mask, wildcard and host capacity.

02

VLSM planner

Describe the networks and host counts you need, then generate an allocation from the largest block to the smallest.

03

Mask converter

Convert subnet masks and Cisco-style wildcard masks, with the equivalent contiguous prefix when one exists.
