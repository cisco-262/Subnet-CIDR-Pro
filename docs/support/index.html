Support

Get help with IPv4 calculations, mask conversion, VLSM planning or the built-in prefix reference.

Contact

Email support@opshome.run or contact @opshome_NOC on X.

Include the app version, iOS version, device model, the input that caused the issue and the result you expected. Remove any sensitive network information before sending.

Common checks

  • Enter an IPv4 address as four decimal octets, optionally followed by a prefix such as 192.168.1.100/26.
  • Prefixes must be between /0 and /32.
  • A VLSM parent network must include a prefix and have enough space for every requested host block.
  • Noncontiguous wildcard masks do not map to one CIDR prefix.
  • /31 is treated as a two-address point-to-point network; /32 is treated as a single host.

Privacy

Calculations run locally. If an example contains internal addressing you do not want to share, replace it with a documentation or private test range that reproduces the same behavior.
