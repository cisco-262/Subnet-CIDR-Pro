SUBNET CIDR PRO

支持

获取 IPv4 计算、掩码转换、VLSM 规划或内置前缀参考方面的帮助。

联系我们

发送邮件至 support@opshome.run，或通过 X 联系 @opshome_NOC。

请提供 App 版本、iOS 或 iPadOS 版本、设备型号、出现问题的输入和预期结果。发送前请移除敏感网络信息。

常见检查

  • IPv4 地址应包含四个十进制段，可附带类似 192.168.1.100/26 的前缀。
  • 前缀必须位于 /0 至 /32。
  • VLSM 父网络必须包含前缀，并能够容纳全部主机需求。
  • 非连续通配符掩码无法对应单一 CIDR 前缀。
  • /31 按两个地址的点到点网络处理，/32 按单主机处理。

隐私提示

所有计算均在本地完成。如果示例包含不希望分享的内部地址，请替换成能够复现同一问题的测试地址。
